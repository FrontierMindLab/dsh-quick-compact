# experiments · 实验区（维护方：主控会话）

本区只放**实验脚本、脱敏 fixture、聚合结果**，不放日志原文、本机路径、凭据。

## 目录
- `bench/` — 性能基准（压缩耗时、上下文占用、一次 /compact 的往返）
- `ab/` — A/B 对比（有/无 quick-compact 的同任务对照）
- `fixtures/` — 脱敏样例输入（合成数据；不含真实用户内容）
- `results/` — 只放聚合指标 JSON：`YYYYMMDD-<实验名>.json`

## 红线（提交前自查）
1. 不出现绝对路径（本机用户主目录、家目录样式都不要）、主机名、用户名。
2. 不出现 token / API key / cookie / 私钥 / 设备码；CI 与 gitleaks 会扫，但别依赖它们兜底。
3. 不放聊天原文、日志原文；需要证据时放"指标 + 复现命令"。
4. 结果文件只含聚合值（均值/中位数/样本数），不含单条输入内容。

## 复现
每个实验目录的 README 写清：目的、命令、需要的环境（Node 版本）、预计耗时、结果判读方式。
